# ASM Graphics Project

A graphical drawing program in 8086 assembly that draws shapes using BIOS interrupts.

## How to Run This Code

### Setup 

1. **Install VS Code**
2. **Install MASM/TASM extension** (by tekin-cn)
3. **Configure the extension:**
   - Press `Ctrl + ,` (Settings)
   - Search: `masmtasm.ASM.emulator`
   - Change from `dosbox` to `jsdos`
4. **Restart VS Code**

### Run the Program

1. Open `test.asm`
2. Right-click anywhere in the file
3. Select **"Run ASM code"**
4. DOSBox will open and show the graphics
5. Press any key to exit
